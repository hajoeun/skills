# Phase 2 Step 2: Whisper 자막 교정

## 개요

Whisper 자동 생성 자막의 오류를 concept.md 맥락 기반으로 교정한다. 편집 가이드의 정확성은 자막 품질에 직접 의존하므로, 편집 가이드 생성(Step 3) 전에 반드시 수행한다.

핵심 원칙: **AI는 교정 목록을 제시하고, 사용자가 검토한 뒤에만 반영한다.** 구어체 표현이나 의도적 비문을 잘못 고칠 위험이 있기 때문이다.

---

## 워크플로우

### 준비

1. 원본 SRT 백업: `cp '자막.srt' '자막_원본.srt'`
2. concept.md에서 고유명사 목록 추출:
   - 인명 (호스트, 게스트, 언급되는 인물)
   - 서비스명/제품명
   - 회사명/기관명
   - 기술 용어 (AI 도구, 프레임워크, 비즈니스 용어)

### 1단계: 고유명사 일괄 교정

concept.md의 고유명사를 기준으로 Whisper 오인식을 탐색하고 교정한다. 이 단계는 사용자 확인 없이 바로 수행할 수 있다 — 고유명사는 정답이 명확하기 때문이다.

1. concept.md에서 추출한 고유명사 목록 확인
2. 아래 "흔한 Whisper 한국어 오류 패턴"을 참조하여, 각 고유명사의 예상 오인식 패턴을 Grep으로 SRT 전체에서 탐색
3. 발견된 오류를 일괄 교정 (Edit replace_all)
4. 교정 결과를 테이블로 사용자에게 공유

### 2단계: 문맥 기반 오탈자 교정

Whisper가 발음이 비슷한 다른 단어로 변환한 오류를 찾는다. 이 단계는 반드시 사용자 검토를 거쳐야 한다.

1. SRT 파일을 ~200줄씩 구간별로 읽으며 오류 탐색
2. 교정 대상을 확신도별로 분류하여 사용자에게 테이블로 제시 (아래 "사용자 협업 프로토콜" 참조)
3. 사용자 피드백을 받은 후 승인된 항목만 교정

**교정 대상 유형:**
- 동음이의어 오변환 (예: 추첨→추천, 해자→혜자)
- 영문 용어 한글 오변환 (예: SaaS→쌀쓰, IDE→아이디)
- 조사/어미 오류
- 서비스명/인명 단순 오인식 (1단계에서 놓친 것)

**교정하지 않는 것:**
- 구어체 특유의 비문 (실제 발화 그대로 유지)
- 타임스탬프 (텍스트만 수정)
- 이미 자연스러운 말투/반복

## 사용자 협업 프로토콜

### Step 1: AI가 교정 목록 제시

확신도별로 분류한 테이블을 사용자에게 보여준다:

**확실한 오류** — 맥락상 명백히 틀린 것. 사용자 동의 시 바로 교정.

| # | 라인 | 현재 텍스트 | 교정안 | 근거 |
|---|------|------------|--------|------|
| 1 | 299 | 추**천** 티켓팅 | 추**첨** 티켓팅 | 추첨(lottery) 맥락 |

**높은 확률** — 문맥상 맞을 가능성 높으나 음성 확인이 이상적.

| # | 라인 | 현재 텍스트 | 교정안 | 근거 |
|---|------|------------|--------|------|
| 33 | 459 | 바로 **레포트** 했던 | **레포 팠던** | 저장소 생성 맥락 |

**판단 보류** — 음성 없이는 확인 불가.

| # | 라인 | 현재 텍스트 | 추정 | 이유 |
|---|------|------------|------|------|
| 41 | 351 | **주훈이** 말한 | 인명? | 특정 불가 |

### Step 2: 사용자 응답

사용자는 항목별로 응답한다:
- **동의** → 교정안 그대로 적용
- **수정** → "N번은 X로 바꿔" (사용자가 정확한 표현 제시)
- **패스** → 건너뜀 (나중에 편집 시 자를 내용 등)

### Step 3: 승인된 항목만 일괄 교정

사용자 피드백을 반영하여 교정 실행 → diff로 결과 공유 → 줄 수 변동 없음 확인.

## 3단계: 검증

```bash
python3 scripts/parse_srt.py '<file.srt>' --validate
```

- SRT 포맷 유효성 확인
- 원본 대비 diff로 전체 변경점 리뷰
- 수정 전후 엔트리 수 동일 확인
- 타임스탬프 변경 없음 확인

## Whisper 오류 패턴 참조

프로젝트별로 발견된 Whisper 오인식 패턴은 `~/.veast/whisper_patterns.json`에 누적 관리한다.
교정 1단계(고유명사 Grep 탐색) 시 이 파일을 읽어 기존 패턴을 참조하고, 새로 발견된 패턴은 교정 완료 후 추가한다.

- **파일 경로**: `~/.veast/whisper_patterns.json`
- **읽기 시점**: 자막 교정 1단계 시작 시
- **쓰기 시점**: 자막 교정 완료 후, 새로 발견된 패턴 추가
- **구조**: 아래 형식 참조

```json
{
  "proper_nouns": [
    { "whisper": "채찍피티", "actual": "ChatGPT", "category": "AI 도구" }
  ],
  "homophones": [
    { "whisper": "추천", "actual": "추첨", "context": "티켓팅/복권 맥락" }
  ],
  "abbreviations": [
    { "whisper": "피우", "actual": "PO", "type": "직책 약어" }
  ]
}
```
