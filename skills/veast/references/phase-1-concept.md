# Phase 1: 컨셉 도출

## 개요

새 영상 프로젝트를 시작하고, 프로젝트 유형에 맞는 기획안(concept.md)을 생성한다.
`_history.json`의 채널 인사이트를 참조하여 이전 영상에서 효과적이었던 패턴을 반영한다.

5가지 영상 유형을 지원하며, 각 유형별로 다른 질문/장면 구조와 프롬프트를 사용한다.

## 영상 유형별 컨셉 구조

| 유형 | GuestInfo 해석 | 섹션 구조 | 항목 수 |
|------|---------------|----------|---------|
| **인터뷰** | guest = 인터뷰이 | 오프닝(Hook) / 본론 / 마무리 | 2 / 4-6 / 1-2 |
| **브이로그** | name=주인공, topics=촬영 테마 | 도입(일상진입) / 핵심장면 / 클로징(회고) | 1-2 / 3-5 / 1 |
| **팟캐스트** | guest = 출연자/공동호스트 | 인트로(주제소개) / 토크포인트 / 아웃트로 | 1-2 / 5-8 / 1-2 |
| **탐방로그** | name=장소명, title=장소유형 | 기대감 조성 / 탐방 포인트 / 총평 | 1-2 / 4-6 / 1 |
| **숏폼** | name=주제, topics=핵심 키워드 | 훅(0-3초) / 핵심 전달 / CTA | 1 / 1-2 / 1 |

> **참고**: `GuestInfo` 모델은 동일하지만, 유형에 따라 `name`, `title`, `topics` 필드의 의미가 달라진다.
> 인터뷰/팟캐스트에서는 guest 정보가 필수이고, 브이로그/탐방로그/숏폼에서는 선택사항이다.

## 워크플로우

### 1. 프로젝트 생성

- `project.json` 파일을 새로 생성
- 유형에 맞는 정보 기록 (인터뷰이/장소/주제 등)
- Phase 1 상태를 `in_progress`로 설정

### 2. 리서치

웹 검색으로 관련 정보를 보강한다:

**인터뷰/팟캐스트**: 출연자의 최근 활동, 발표, SNS 활동, 관련 뉴스
**브이로그**: 촬영 테마 관련 트렌드, 유사 콘텐츠 분석
**탐방로그**: 장소 리뷰, 최근 이슈, 방문 팁
**숏폼**: 주제 관련 트렌드, 바이럴 패턴

검색 전략:
- `"{대상 이름}" + {분야/주제}` 기본 검색
- 최근 6개월 내 활동 중심
- 한국어 + 영어 양쪽 검색

### 3. 채널 히스토리 참조

`_history.json`이 존재하면:
- `insights.top_performing_topics`에서 채널의 인기 주제 확인
- `insights.retention_patterns`에서 효과적인 구성 패턴 참조
- 과거 유사 주제의 성과 데이터 분석
- 이전 영상의 `learnings`에서 개선 포인트 수집

### 4. 기획안 생성

`concept_generator.py`가 `project.type`에 따라 적절한 프롬프트를 자동 선택한다.

공통 원칙:
- 시청자가 궁금해할 내용 우선
- 채널 과거 데이터에서 높은 리텐션을 보인 패턴 반영
- 각 항목에 편집 시 역할 태깅

## 프롬프트 구조

### 시스템 프롬프트 (공통 베이스)

```
당신은 유튜브 크리에이터의 기획 전문가입니다.

채널 과거 데이터와 리서치를 기반으로, 시청자 관심을 극대화하는 콘텐츠 기획안을 설계합니다.
단순히 정보를 나열하지 않고, 시청자의 감정과 행동을 유도하는 구성을 만듭니다.

공통 원칙:
- 채널 과거 데이터에서 높은 리텐션을 보인 패턴 반영
- 각 항목에 편집 시 역할을 미리 태깅
- 시청자가 검색하거나 댓글로 궁금해할 내용 우선 배치

출력은 한국어로 작성합니다.
```

각 유형별로 `system_addendum`이 추가되어 유형 특화 지시를 제공한다.
구현: `concept_generator.py`의 `PROMPT_CONFIGS` 딕셔너리 참조.

### 입력 변수

| 변수 | 소스 | 설명 |
|------|------|------|
| `{guest_name}` | project.json | 인터뷰이/장소/주제 이름 |
| `{guest_title}` | project.json | 직업/유형/카테고리 |
| `{guest_topics}` | project.json | 예상 주제/촬영 테마/키워드 |
| `{target_audience}` | project.json | 타겟 시청자 |
| `{target_views}` | project.json | 목표 조회수 |
| `{expected_length}` | project.json | 예상 영상 길이 |
| `{history_context}` | _history.json | 채널 인사이트 (자동 포맷팅) |
| `{web_search_results}` | 웹 검색 | 최근 활동 검색 결과 |

## Few-shot 예시

### 예시 1: AI 스타트업 CEO 인터뷰

**입력 (요약):**
- 유형: 인터뷰
- 게스트: 박지훈, AI 스타트업 CEO
- 주제: AI 창업, 투자 유치
- 채널 인기 주제: 해커톤, 창업, AI
- 효과적 패턴: hook_in_first_30s (avg_retention 48.2%)

**출력:**

```markdown
# 컨셉: 박지훈 AI 창업 인터뷰

## 인터뷰이 프로필

- **이름**: 박지훈
- **직업**: AI 스타트업 CEO (NeuroLab)
- **주요 경력**: 카이스트 AI 석사, 전 구글 ML 엔지니어, 2025년 시드 투자 50억 유치
- **최근 활동**: AI 규제 관련 국회 토론회 패널 참석 (2026.03)

## 채널 인사이트

- 유사 주제 과거 성과: AI 관련 영상 평균 CTR 7.1%, 채널 평균 대비 +1.3%p
- 효과적이었던 패턴: 첫 30초 훅 배치 시 리텐션 48.2%

## 질문 리스트

### 오프닝 (Hook 후보)
1. 투자자 50명에게 거절당한 후 50억 투자를 받기까지 가장 결정적이었던 순간은? — 의도: 갈등+반전, 훅으로 편집 가능

### 본론
2. 구글을 나와서 창업하겠다고 했을 때 주변 반응은? — 의도: 감정적 순간, 공감 유도
3. AI 규제 이슈가 스타트업에 실제로 어떤 영향을 주나요? — 의도: 시의성, 검색 트래픽 기대
4. 첫 제품 출시 후 가장 예상 못한 피드백은? — 의도: 구체적 사례, 의외성

### 마무리
5. AI 스타트업을 준비하는 시청자에게 딱 한 가지 조언? — 의도: 실용적 정보, 마무리 감정

## 촬영 메모

- 예상 촬영 시간: 40분
- 목표 최종 영상 길이: 15분
- 특별 주의사항: 투자 거절 경험 이야기 시 자연스러운 표정 변화 클로즈업
```

### 예시 2: 성수동 카페 탐방로그

**입력 (요약):**
- 유형: 탐방로그
- 장소: 성수동 카페거리
- 유형: 카페/디저트
- 탐방 포인트: 인테리어, 시그니처 메뉴, 가성비
- 채널 인기 주제: 맛집, 카페, 서울 핫플
- 효과적 패턴: hook_in_first_30s (avg_retention 52.1%)

**출력:**

```markdown
# 컨셉: 성수동 카페거리 탐방

## 탐방 대상 프로필

- **장소**: 성수동 카페거리
- **유형**: 카페/디저트
- **위치**: 서울 성동구 성수동
- **특징**: 공장 리모델링 카페, SNS 인기 핫플레이스, 2026년 신규 오픈 매장 다수

## 채널 인사이트

- 유사 주제 과거 성과: 카페 탐방 영상 평균 CTR 8.2%, 채널 평균 대비 +2.4%p
- 효과적이었던 패턴: 첫 30초 음식 클로즈업 시 리텐션 52.1%

## 탐방 포인트

### 기대감 조성 (외부/첫인상)
1. 성수동 거리 전경 + "여기 다 가보겠습니다" 선언 — 의도: 훅, 시청 목표 설정
2. 첫 번째 카페 외관 + 대기줄 리액션 — 의도: 궁금증 유발

### 탐방 포인트
3. A카페 시그니처 디저트 실물 공개 + 첫 맛 리액션 — 의도: 감각적 장면, 메인 콘텐츠
4. B카페 인테리어 투어 + 가격 공개 — 의도: 정보(가격) + 감성(공간)
5. C카페 숨겨진 메뉴 주문 — 의도: 의외성, 차별화 포인트
6. 가격 비교 정리 (가성비 순위) — 의도: 실용 정보, 시청자 참고용

### 총평 (추천 여부)
7. 성수동 카페 Top 3 + 재방문 의사 — 의도: 마무리, 명확한 결론 제시

## 촬영 메모

- 예상 촬영 시간: 3시간
- 목표 최종 영상 길이: 12분
- 특별 주의사항: 음식 클로즈업 필수, 각 카페 가격표 촬영
```

## concept.md 출력 템플릿

유형별 출력 형식은 `concept_generator.py`의 `PROMPT_CONFIGS`에 정의된 각 유형의 `user_template` 내에 포함되어 있다.

### 인터뷰

```markdown
# 컨셉: {프로젝트 이름}

## 인터뷰이 프로필
- **이름** / **직업** / **주요 경력** / **최근 활동**

## 채널 인사이트

## 질문 리스트
### 오프닝 (Hook 후보) — 2개
### 본론 — 4-6개
### 마무리 — 1-2개

## 촬영 메모
```

### 브이로그

```markdown
# 컨셉: {프로젝트 이름}

## 주인공 프로필
- **이름** / **직업** / **촬영 테마**

## 채널 인사이트

## 장면 구성
### 도입 (일상 진입) — 1-2개
### 핵심 장면 — 3-5개
### 클로징 (회고) — 1개

## 촬영 메모
```

### 팟캐스트

```markdown
# 컨셉: {프로젝트 이름}

## 출연자 프로필
- **이름** / **직업** / **주요 경력** / **최근 활동**

## 채널 인사이트

## 토크 포인트

```

```markdown
## 탐방 포인트

### 탐방 포인트 — 4-6개

## 촬영 메모
```

```markdown
## 콘텐츠 구성
### 훅 (0-3초) — 1개
```
