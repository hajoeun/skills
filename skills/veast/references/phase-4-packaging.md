# Phase 4: 패키징 제안

## 개요

SRT 자막과 concept.md를 기반으로 제목 후보와 썸네일 방향을 제안한다.
사용자가 최종 선택하고, 썸네일은 기존 피그마 템플릿으로 직접 제작한다.

## 워크플로우

### 1. 콘텐츠 분석

다음 소스에서 핵심 메시지를 추출:
- `concept.md`: 기획 의도, 인터뷰이 프로필
- SRT 자막: 실제 발화 내용, 하이라이트 구간
- `edit-guide.md`: 편집 구성, 훅으로 선정된 구간

### 2. 제목 전략

5가지 전략으로 각 1개씩 제목 후보를 생성한다:

| 전략 | 설명 | 예시 |
|------|------|------|
| 호기심 유발 | 답을 알고 싶게 만드는 질문/미완성 문장 | "해커톤 1등이 진짜 중요하다고 말한 것" |
| 숫자형 | 구체적 숫자로 클릭 유도 | "3번 실패 후 해커톤 1등한 방법 5가지" |
| 하우투 | 실용적 가치 전달 | "해커톤 우승하는 법 (현직 CTO가 알려줌)" |
| 대립/반전 | 통념을 뒤집는 주장 | "해커톤 1등은 코딩을 제일 못했다" |
| 개인 스토리 | 감정적 연결 | "6개월 준비한 해커톤에서 일어난 일" |

### 3. 제목 평가 기준

각 후보에 대해:
- `_history.json`의 `title_patterns`와 비교하여 예상 CTR 제시
- 50자 이내 권장 (유튜브 검색 결과에서 잘림 방지)
- SEO 키워드 포함 여부

### 4. 썸네일 방향

제목별로 매칭되는 썸네일 방향을 제안:
- 메인 비주얼: 인물 표정, 텍스트 오버레이, 소품
- 색감/톤: 밝은/어두운, 따뜻한/차가운
- 텍스트: 제목과 다른 짧은 카피 (3~5단어)
- 레이아웃: 인물 위치, 텍스트 위치

## 프롬프트 템플릿

### 시스템 프롬프트

```
당신은 유튜브 SEO와 마케팅 전문가입니다.

영상 콘텐츠의 핵심 메시지를 파악하고, 채널 과거 데이터를 기반으로
CTR을 극대화하는 제목 전략과 썸네일 방향을 제안합니다.

제목 작성 원칙:
- 50자 이내 (유튜브 검색 결과에서 잘리지 않도록)
- 5가지 전략(호기심, 숫자형, 하우투, 대립/반전, 개인 스토리)으로 각 1개씩
- 채널 과거 데이터에서 CTR이 높았던 패턴 우선 적용
- SEO 키워드를 자연스럽게 포함

썸네일 방향:
- 제목과 다른 짧은 카피 (3~5단어) — 제목을 반복하지 않음
- 인물 표정, 색감, 레이아웃 구체적으로 기술

출력은 한국어로 작성합니다.
```

### 입력 변수

| 변수 | 소스 | 설명 |
|------|------|------|
| `{{srt_text}}` | SRT 파일 | 자막 전문 (핵심 발화 추출용) |
| `{{concept.md}}` | Phase 1 산출물 | 기획 의도, 인터뷰이 프로필 |
| `{{edit-guide.md}}` | Phase 2 산출물 | 편집 구성, 훅 구간 |
| `{{_history.insights.title_patterns}}` | _history.json | 제목 전략별 CTR 통계 |
| `{{_history.insights.avg_ctr}}` | _history.json | 채널 평균 CTR |
| `{{project.meta.guest.name}}` | project.json | 게스트 이름 |

### 사용자 메시지 구성

```
아래 정보를 바탕으로 유튜브 제목 후보 5개와 썸네일 방향을 제안해주세요.

## 기획 의도
{{concept.md}}

## 편집 구성 (훅 구간)
{{edit-guide.md}} 중 Hook 섹션

## 핵심 발화 (SRT에서 인상적인 구간)
{{srt_text}} 중 관심도 높은 구간 요약

## 채널 데이터
- 제목 패턴별 CTR: {{_history.insights.title_patterns}}
- 채널 평균 CTR: {{_history.insights.avg_ctr}}%

## 요청 사항
1. 5가지 전략으로 각 1개씩 제목 후보를 만드세요.
2. 각 제목에 예상 CTR을 제시하세요 (채널 데이터 기반).
3. 제목별 썸네일 방향을 제안하세요.
4. 최종 추천 1순위를 선택하고 이유를 설명하세요.
```

## Few-shot 예시

### 예시 1: 해커톤 인터뷰 패키징

**입력 (요약):**
- 게스트: 홍길동, 스타트업 CTO
- 훅: 해커톤 3번 실패 후 1등
- 채널 제목 패턴: 숫자형 avg_ctr 7.1%, 호기심 avg_ctr 6.2%

**출력:**

```markdown
# 패키징 제안: 홍길동 인터뷰

## 제목 후보

| # | 전략 | 제목 | 예상 CTR | 글자수 |
|---|------|------|---------|--------|
| 1 | 호기심 | 해커톤 1등이 진짜 중요하다고 말한 것 | 6.5% | 20자 |
| 2 | 숫자형 | 3번 떨어진 해커톤, 4번째에 1등한 비결 | 7.3% | 22자 |
| 3 | 하우투 | 해커톤 우승하는 법 (현직 CTO가 알려줌) | 5.8% | 22자 |
| 4 | 대립 | 해커톤 1등은 코딩을 제일 못했다 | 6.8% | 17자 |
| 5 | 스토리 | 6개월 준비한 해커톤에서 일어난 일 | 6.0% | 18자 |

채널 평균 CTR: 5.8%

## 썸네일 방향

### 제목 2 — 3번 떨어진 해커톤, 4번째에 1등한 비결
- 비주얼: 홍길동이 트로피를 들고 놀란 표정
- 톤: 어두운 배경 + 밝은 스팟라이트
- 텍스트: "4전 5기"
- 레이아웃: 인물 좌측 2/3, 텍스트 우측 상단

## 추천

1순위: 제목 2 — 이유: 숫자형 전략이 채널 평균 대비 CTR +1.3%p. 구체적 숫자(3번, 4번째)가 호기심 유발.
```
