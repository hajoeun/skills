# Phase 5: 업로드 키트 (타임스탬프 + 설명란)

## 개요

편집 완료 후 최종 SRT를 기반으로 타임스탬프와 YouTube 설명란 텍스트를 자동 생성한다.
바로 복사-붙여넣기할 수 있는 형태로 출력한다.

## 워크플로우

### 1. 타임스탬프 생성

편집 가이드의 sequence 라벨과 최종 타임코드를 기반으로 챕터 타임스탬프를 생성:

- 각 sequence 라벨 = 하나의 챕터
- 시작 타임코드를 `MM:SS` 또는 `H:MM:SS` 형식으로 변환
- 첫 타임스탬프는 반드시 `0:00`에서 시작 (YouTube 챕터 요구사항)
- 챕터명은 시청자 친화적으로 다듬기 (편집 라벨 그대로가 아닌)

### 2. 설명란 구성

YouTube 설명란의 구조:
1. **인트로 문장** (1~2줄): 영상 핵심 내용 요약
2. **타임스탬프**: 챕터 목록
3. **인터뷰이 정보**: SNS 링크, 관련 콘텐츠
4. **채널 정보**: 구독/좋아요 안내, SNS 링크
5. **해시태그**: 관련 키워드 5~10개

### 3. 해시태그 선정

- concept.md의 주제에서 추출
- SRT 자막에서 자주 등장하는 키워드
- `_history.json`에서 성과 좋았던 영상의 해시태그 패턴 참조
- 한국어 + 영어 혼합

## 프롬프트 템플릿

### 시스템 프롬프트

```
당신은 유튜브 콘텐츠 매니저입니다.

편집된 영상의 구조를 이해하고, 시청자 경험을 최적화하는 타임스탬프와 설명란을 작성합니다.
YouTube에 바로 복사-붙여넣기할 수 있는 완성된 텍스트를 출력합니다.

타임스탬프 원칙:
- 첫 타임스탬프는 반드시 0:00에서 시작 (YouTube 챕터 요구사항)
- 챕터명은 편집 라벨 그대로가 아닌, 시청자 친화적으로 다듬기
- MM:SS 형식 (1시간 미만), H:MM:SS 형식 (1시간 이상)

설명란 원칙:
- 인트로 1~2줄로 영상 핵심 전달
- 해시태그 5~10개 (한국어 + 영어 혼합)
- 이모지는 절제하되, 섹션 구분용으로 활용

출력은 한국어로 작성합니다.
```

### 입력 변수

| 변수 | 소스 | 설명 |
|------|------|------|
| `{{final_srt_text}}` | 편집 후 SRT | 최종 편집본의 자막 텍스트 |
| `{{edit_guide_sequence}}` | edit-guide.yaml | 편집 순서 라벨 + 타임코드 |

## Few-shot 예시

### 예시 1: 인터뷰 업로드 키트

**입력 (요약):**
- 편집 순서: Hook(0:00), 자기소개(0:32), 해커톤 도전기(1:15), 교훈(8:42), 마무리(12:05)
- 게스트: 홍길동, 스타트업 CTO
- 제목: "3번 떨어진 해커톤, 4번째에 1등한 비결"

**출력:**

```markdown
# 업로드 키트: 홍길동 인터뷰

## 타임스탬프 (복사용)

0:00 해커톤 우승의 순간
0:32 홍길동은 누구?
1:15 3번의 실패 이야기
8:42 실패에서 배운 것들
12:05 시청자에게 전하는 한마디

## 설명란 (복사용)

해커톤에 3번 떨어지고도 포기하지 않은 스타트업 CTO 홍길동. 4번째 도전에서 1등을 한 비결은 의외로 단순했습니다.

⏱ 타임스탬프
0:00 해커톤 우승의 순간
0:32 홍길동은 누구?
1:15 3번의 실패 이야기
8:42 실패에서 배운 것들
12:05 시청자에게 전하는 한마디

📌 홍길동
- LinkedIn: https://linkedin.com/in/gildong

🎬 {채널명}
- 구독: https://youtube.com/@{채널_핸들}
- Instagram: https://instagram.com/{인스타_핸들}

#해커톤 #스타트업 #CTO인터뷰 #창업 #hackathon #startup #개발자인터뷰 #도전 #실패극복
```
