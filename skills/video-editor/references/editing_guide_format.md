# 편집 가이드 작성 포맷

이 문서는 video-editor 스킬에 전달할 편집 가이드의 작성 방법을 설명합니다.

## 필수 구성 요소

편집 가이드에는 최소한 **재배치 순서**가 포함되어야 합니다.
원본 구획 맵은 선택사항이지만 복잡한 편집에서 가독성을 높여줍니다.

---

## 1. 원본 구획 맵 (선택)

영상 전체를 의미 있는 구간으로 나눈 표입니다. 편집 계획의 기반이 됩니다.

```markdown
| 구획 | 자막 # | 타임코드 | 내용 |
|------|--------|----------|------|
| A | #1~#18 | 00:00~00:33 | 인트로 + 자기소개 |
| B | #19~#137 | 00:33~04:15 | 해커톤 1등 이야기 |
| C | #138~#202 | 04:15~06:23 | 두 번째 해커톤 |
```

- **구획**: 영문 알파벳으로 레이블링 (A, B, C, ...)
- **자막 #**: SRT 파일의 자막 번호 범위 (`#시작~#끝`)
- **타임코드**: 대략적 시간 범위 (참고용)
- **내용**: 해당 구간의 내용 요약

## 2. 재배치 순서 (필수)

완성 영상의 순서대로 섹션을 나열합니다. 각 섹션에 사용할 자막 범위와
처리 방법을 명시합니다.

```markdown
### 1. Hook (0:00~0:30)

| 순서 | 가져올 곳 | 자막 # | 처리 |
|------|-----------|--------|------|
| 컷1 | 구획 B | #69~#75 | 전체 사용 |
| 컷2 | 구획 C | #196~#200 | 전체 사용 |
| 인트로 | 구획 A | #1~#8 | 전체 사용 |

### 2. 본론 (~3분)

| 순서 | 가져올 곳 | 자막 # | 처리 |
|------|-----------|--------|------|
| 제품소개 | 구획 F | #342~#394 | 전체 사용 |
| 배경설명 | 구획 D | #203~#247 | 30초로 압축 |

잘라내는 것:
- #248~#272 (부정적 반응 부분)
```

### 자막 번호 표기 방법

아래 형식들을 모두 인식합니다:
- `#69~#75`
- `#69-#75`
- `69번~75번`
- `자막 69~75`
- `#69~75`

### 처리 지시 종류

| 지시 | 의미 |
|------|------|
| 전체 사용 | 해당 자막 범위의 영상 전체를 사용 |
| N초로 압축 | 가이드에 명시된 세부 범위만 사용 (잘라내는 것 참고) |
| 핵심만 | 가이드에 명시된 세부 범위만 사용 |
| 잘라냄 / 삭제 / 제외 | 해당 구간을 편집에서 제외 |

## 3. 최종 편집 순서 요약 (선택)

전체 흐름을 한눈에 볼 수 있는 축약 표기입니다.

```
[Hook]     B#69~75 → C#196~200 → A#1~8
[본론]     F#342~394 → D#203~247(압축)
[클로징]   O#889~893
```

---

## 예시

아래는 인터뷰 영상의 편집 가이드 예시입니다:

```markdown
# 편집 가이드

## 재배치 순서

### 1. 오프닝

| 순서 | 자막 # | 설명 |
|------|--------|------|
| 하이라이트 | #45~#52 | 인상적인 발언 |
| 인트로 | #1~#10 | 인사 + 소개 |

### 2. 본론

| 순서 | 자막 # | 설명 |
|------|--------|------|
| 핵심 이야기 | #80~#150 | 메인 주제 |
| 경험담 | #200~#250 | 구체적 사례 |

잘라내는 것:
- #120~#135 (주제에서 벗어난 잡담)

### 3. 클로징

| 순서 | 자막 # | 설명 |
|------|--------|------|
| 마무리 | #300~#320 | 핵심 정리 + 인사 |
```
